GitHub Repository玩法與產品功能

這是什麼產品？

這是線上多人德州撲克房間與桌台服務的核心程式。房間、玩家、桌台、訊息與訂單介面，呈現配對、入桌、下注、旁觀、離線重連到結果記錄的服務端流程。完整上線仍需外部設定、資料庫、閘道、客戶端與安全合規能力。

買入流程

從選擇座位到帶入籌碼

玩家進入有效牌局前，可在買入介面選擇房間規則允許的金額。服務端同步餘額、座位與遊戲狀態；私人房亦可透過房主設定控制買入倍數。

  • 依房間規則限制買入區間
  • 關聯玩家座位與牌局狀態
  • 私人房房主可設定買入倍數

俱樂部營運

基金發放、帳戶變化與流水記錄

俱樂部畫面展示基金發放、餘額變化和歷史流水，並與程式中的俱樂部房間資料相互對應。營運人員可查看具體記錄，而非只有籠統入口。

  • 俱樂部基金發放與確認
  • 成員餘額變化記錄
  • 房間、成員與管理資訊

營運流程

與俱樂部管理相連的基金轉帳

轉帳頁面呈現私人房與俱樂部房之外的營運流程。正式上線時，這些操作仍須接入身分驗證、資料庫記錄、風險控制，並遵守所在地支付與遊戲營運規範。

  • 接收方與金額輸入流程
  • 確認後再建立記錄
  • 正式環境風控與合規仍需整合

C++ / Tars 技術架構

RoomServant、Room、PlayerMng 與不同 TableManager 構成核心房間服務。

Client / Gateway
RoomServant · OrderServant
Room · PlayerMng · TableManager
Quick · AOF · Short Deck · Private · SNG · MTT
  • Player matching, seating, watching, offline and re-entry states
  • Betting, buy-in, extension, auto-play, insurance and Run It Twice messages
  • Hand history, result collection and club-room data
  • Dynamic .so modules plus iOS / Google Play order interfaces

此倉庫主要展示核心服務與協定程式，並非單獨複製即可上線的完整成品。正式環境仍需 Tars、設定中心、資料庫/快取、閘道、客戶端、支付憑證、監控、安全與合規配置。
